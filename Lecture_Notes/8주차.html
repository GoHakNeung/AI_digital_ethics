1 HTML 요소 복습 및 개발자 도구

1. 설명

HTML은 웹의 '뼈대'입니다. <header>(상단), <main>(본문), <footer>(하단)로 나뉘며, 그 안에 버튼이나 글이 배치됩니다.

💡 꿀팁: 브라우저에서 F12를 누르면 '개발자 도구'가 열립니다. 여기서 HTML 구조와 적용된 CSS를 직접 확인할 수 있습니다.

2. 예시 코드

<main>
  <h1>퀴즈</h1>
  <button>시작</button>
</main>

3. 프롬프트 예시

2 CSS란 무엇인가?

1. 설명

CSS(Cascading Style Sheets)는 HTML 뼈대 위에 입히는 옷과 피부(스타일)입니다. 디자인을 예쁘게 꾸며 학생들의 학습 몰입도를 높여줍니다.

2. 예시 코드

<!-- [적용 후] -->
<style>
  h1 { color: blue; text-align: center; }
</style>
<h1>디지털 윤리 퀴즈</h1>

3. 프롬프트 예시

"앞서 만든 HTML 뼈대에 CSS를 추가해서, 학생들이 보기에 지루하지 않고 깔끔한 디자인으로 꾸며줘."

3 CSS를 적용하는 방법

1. 설명

태그에 직접 붙이기, 별도 파일 만들기 등이 있지만, 바이브 코딩으로 실습할 때는 복사하기 편하게 HTML의 <head> 안에 <style> 태그로 넣는 방식(Internal)을 주로 씁니다.

4 선택자 (누구를 꾸밀 것인가?)

1. 설명

  • 태그: 화면의 모든 해당 태그를 바꿈 (예: button { })
  • 클래스(.): 점으로 시작. 묶어서 바꿈 (예: .btn { })
  • 아이디(#): 샵으로 시작. 화면에서 유일한 하나만 바꿈 (예: #score { })

2. 예시 코드

<style>
  .correct-btn { color: green; } /* 클래스 */
  #total { font-size: 20px; color: red; }    /* 아이디 */
</style>
<button class="correct-btn">정답 1</button>
<button class="correct-btn">정답 2</button>
<button class="wrong-btn">오답</button>
<p id="total">100점</p>

3. 프롬프트 예시

"정답 버튼들은 묶어서 클래스명(class='correct')을 주고 초록색으로 칠해줘. 최종 점수 칸은 하나뿐이니 아이디(id='total')를 주고 크게 해줘."

5 박스 모델 (Padding과 Margin)

1. 설명

여백을 조절하여 답답함을 없앱니다.

  • padding (안쪽 여백): 테두리와 글씨 사이. 뚱뚱해짐.
  • margin (바깥 여백): 테두리 바깥쪽. 남들과 멀어짐.

2. 예시 코드

<style>
  .box {
    padding: 20px; /* 안으로 20px 통통해짐 */
    margin: 15px;  /* 밖으로 15px 띄어짐 */
    border: 1px solid black;
  }
</style>

<button class="box">버튼 1</button>
<button class="box">버튼 2</button>

3. 프롬프트 예시

"모바일에서 터치하기 편하게 버튼의 안쪽 여백(padding)을 늘려주고, 다닥다닥 붙지 않게 바깥 여백(margin)도 15px씩 띄워줘."

7 글꼴과 정렬 (웹 폰트 적용)

1. 설명

텍스트를 좌/우/중앙으로 정렬(text-align)합니다. (중요) '나눔글꼴' 등을 어떤 기기에서나 띄우려면, PC에 폰트가 없어도 다운로드받아 보여주는 '구글 웹폰트'를 추가해 달라고 AI에게 요구해야 합니다.

2. 예시 코드

<style>
  /* 구글 폰트(나눔펜스크립트) 불러오기 */
  @import url('https://fonts.googleapis.com/...');

  h1 { 
    font-family: 'Nanum Pen Script', cursive; 
    text-align: center; 
  }
</style>

<h1>우리가 지키는 디지털 윤리</h1>

3. 프롬프트 예시

8 화면 배치 (Flexbox로 나란히)

1. 설명

위아래로 쌓이는 요소들을 가로로 나란히 배치할 때 쓰는 마법의 속성입니다.

  • display: flex;: 가로 배치의 시작.
  • justify-content: center;: 가로축 중앙에 예쁘게 모음.

2. 예시 코드

<style>
  .menu {
    display: flex; 
    justify-content: center; 
    gap: 15px; /* 버튼 사이 간격 */
  }
</style>

<div class="menu">
  <button>버튼 1</button>
  <button>버튼 2</button>
</div>

3. 프롬프트 예시

"메뉴 버튼 2개가 세로로 쌓여있는데, 이 상자에 display: flex를 써서 가로로 나란히 배치하고 justify-content로 화면 가운데로 예쁘게 모아줘."

9 화면 분할 (Grid로 다단 나누기)

1. 설명

화면의 비율을 바둑판처럼 명확하게 쪼갤 때 사용합니다. 왼쪽엔 설명, 오른쪽엔 퀴즈를 넣는 등 2단 구성에 최고입니다.

2. 예시 코드

<style>
  .main-box {
    display: grid;
    /* 왼쪽 30%, 오른쪽 70%로 쪼갬 */
    grid-template-columns: 30% 70%; 
    gap: 20px;
  }
</style>

<div class="main-box">
  <div>왼쪽 영역</div>
  <div>오른쪽 영역</div>
</div>

3. 프롬프트 예시

"메인 화면을 좌우 2단으로 나눠줘. display: grid를 써서 왼쪽 설명 구역은 30%, 오른쪽 퀴즈 구역은 70% 비율을 차지하게 구성해 줘."

10 반응형 웹 (기기에 맞게 변신)

1. 설명

스마트폰처럼 좁은 화면으로 접속했을 때, 좌우 2단 배치(PC용)가 깨지지 않고 위아래 1단으로 자동으로 바뀌도록 지시합니다.

2. 예시 코드

<style>
  /* 기본은 가로 배치 */
  .box { display: flex; } 

  /* 폭이 600px 이하가 되면 세로(column) 배치로 덮어씀 */
  @media (max-width: 600px) {
    .box { flex-direction: column; }
  }
</style>

<div class="box">
  <div>구역 1</div>
  <div>구역 2</div>
</div>

3. 프롬프트 예시

"이 퀴즈는 학생들이 스마트폰으로도 접속할 거야. 미디어 쿼리(Media Query)를 써서, 모바일 화면(600px 이하)에서는 2단 배치가 위아래 1단으로 쌓이게 반응형으로 짜줘."

12 JavaScript (웹앱의 근육과 뇌)

1. 설명

사용자의 클릭에 반응하거나 점수를 계산하는 '동작'을 담당합니다. <body>의 가장 아래에 <script> 태그를 열고 작성하는 것이 좋습니다.

💡 기본 논리: "A(이벤트)를 하면 -> B를 찾아서 -> C로 바꿔라"

2. 예시 코드 (기본 구조)

<button id="myBtn">클릭</button>
<div id="preview-msg-12" style="opacity: 0; ">JS 코드가 동작했습니다!</div>

<!-- body가 끝나기 직전 -->
<script>
  // id가 myBtn인 요소를 찾아서 클릭 이벤트를 추가함
document.getElementById("myBtn").addEventListener("click", function() {
      // 버튼을 누르면 투명도를 1로 바꿔서 서서히 나타나게 함
      document.getElementById("preview-msg-12").style.opacity = "1";
  });
</script>

3. 프롬프트 예시

"파일을 나누지 말고, HTML 문서 안의 </body> 직전에 <script> 블록을 만들어서 모든 자바스크립트 동작 코드를 넣어줘."

13 요소의 자유로운 배치와 겹치기

1. 설명

시뮬레이션을 만들 때 필수인 CSS 개념입니다. position: absolute로 허공에 띄우고, z-index로 어떤 게 앞/뒤로 겹칠지 순서를 정합니다.

2. 예시 코드

<style>
/* 1. 전체 시뮬레이션을 담을 부모 상자 (기준점 설정) */
  .space-container {
    position: relative; /* 자식 요소들이 이 상자를 기준으로 자리를 잡음 */
    width: 300px;
    height: 300px;
    background-color: #0f172a; /* 우주 같은 어두운 배경 */
    border-radius: 15px;
  }

  /* 2. 태양 스타일: 뒤쪽, 크고, 노란색 */
  .sun {
    position: absolute;
    top: 50px;
    left: 50px;
    width: 120px;          /* 크기를 크게 지정 */
    height: 120px;
    background-color: #facc15; /* 노란색 */
    border-radius: 50%;    /* 동그란 도형으로 만듦 */
    z-index: 1;            /* 뒤쪽에 배치 */
  }

  /* 3. 달 스타일: 앞쪽, 작고, 회색 */
  .moon {
    position: absolute;
    top: 90px;
    left: 110px;           /* 태양과 살짝 겹치도록 위치 조정 */
    width: 70px;           /* 태양보다 작게 지정 */
    height: 70px;
    background-color: #94a3b8; /* 회색 */
    border-radius: 50%;    /* 동그란 도형으로 만듦 */
    z-index: 99;           /* 숫자가 커서 태양보다 앞(위)쪽에 옴 */
  }
</style>
<div class="space-container">
<div class="sun">태양</div>
<div class="moon">달</div>
<div>

3. 프롬프트 예시

"태양계 시뮬레이션을 만들 거야. position: absolute를 써서 태양과 달이 겹치게 배치하고, 달이 태양 앞을 가리도록 달의 z-index 값을 더 높게 설정해 줘."

14 부드러운 움직임 (Transition)

1. 설명

요소의 크기(scale)나 각도(rotate)가 바뀔 때, 뚝뚝 끊기지 않고 transition을 통해 애니메이션처럼 부드럽게 변하도록 지시합니다.

2. 예시 코드

<style>
  .box {
    /* 변형이 생기면 0.5초 동안 부드럽게 이어라 */
    transition: all 0.5s ease; 
  }
  .box:hover {
    /* 1.2배 커지고 10도 회전 */
    transform: scale(1.2) rotate(10deg); 
  }
</style>

<div class="box">마우스 올려봐요</div>

3. 프롬프트 예시

"마우스를 올리면 크기가 살짝 커지게 transform: scale을 넣고, 딱딱하게 끊기지 않도록 CSS에 transition 속성을 추가해서 0.5초 동안 스르륵 부드럽게 움직이게 해줘."

15 요소 숨기기와 나타내기

1. 설명

'정답 해설'이나 '경고 팝업'처럼 평소엔 display: none으로 완전히 지워뒀다가, 버튼을 누르면 나타나게 하는 기법입니다.

2. 예시 코드


<style>
  #hint { 
    display: none; 
    margin-top: 10px;
    padding: 10px;
    background-color: #fef08a; /* 노란색 배경 */
    border-left: 4px solid #eab308;
  }
</style>

<button id="btn" >힌트 보기</button>
<div id="hint" >💡 힌트: 저작권법 제28조를 떠올려보세요!</div>


<script>
  // 버튼을 클릭했을 때
  document.getElementById("btn").addEventListener("click", function() {
    
    // hint 요소의 현재 display 상태를 가져옴
    const hintBox = document.getElementById("hint");
    
    // 만약 숨겨져(none) 있다면 보이게(block) 하고, 아니면 다시 숨김
    if (hintBox.style.display === "none" || hintBox.style.display === "") {
      hintBox.style.display = "block";
      this.innerText = "힌트 숨기기"; // 버튼 글씨 변경
    } else {
      hintBox.style.display = "none";
      this.innerText = "힌트 보기"; // 버튼 글씨 복구
    }
    
  });
</script >

3. 프롬프트 예시

16 마우스 피드백 (Hover & Cursor)

1. 설명

요소가 클릭 가능한지 시각적으로 알려주는 UX(사용자 경험) 기술입니다. 마우스를 올리면(:hover) 모양이 바뀌고 손가락 커서(pointer)가 나옵니다.

<style>
<style>

  .interactive-card {

    border: 2px solid #e2e8f0; /* 기본 연한 회색 테두리 */

17 상태 변경 (화면의 무엇을 바꿀까?)

1. 설명

JS로 이벤트를 감지했다면, 글자(innerText)를 바꾸거나, CSS 색상(style)을 조작하라고 지시합니다.

2. 예시 코드


<p id="preview-text-17">아직 풀지 않음</p>
<button id="preview-btn-17">정답 제출하기</button>


<script>
  // '정답 제출하기' 버튼을 클릭했을 때 이벤트 추가
  document.getElementById("preview-btn-17").addEventListener("click", function() {
    
    // 대상 텍스트 요소를 찾음
    let text = document.getElementById("preview-text-17");
    
    // 1. 글자 내용을 정답으로 변경
    text.innerText = "정답입니다!";
    
    // 2. 글자 색상을 파란색으로 변경 (tailwind 대신 명확한 인라인 스타일 적용)
    text.style.color = "blue";
    
  });
</script>

19 시간 제어 (타이머)

1. 설명

과학 시뮬레이션(지구 자전 등)을 만들 때 유용합니다. setInterval을 사용해 "일정 시간마다 반복해라"라고 요구할 수 있습니다.

2. 예시 코드

<div id="earth">지구</div>

<script>
  let degree = 0;
  // 100ms(0.1초) 마다 5도씩 증가시킴
  setInterval(function() {
    degree += 5; 
    earth.style.transform = `rotate(${degree}deg)`;
  }, 100); 
</script>

3. 프롬프트 예시

"지구가 스스로 돌게 만들고 싶어. 타이머 기능(setInterval)을 써서 0.1초마다 지구 이미지의 회전 각도가 5도씩 계속 증가하도록 동작 코드를 짜줘."
