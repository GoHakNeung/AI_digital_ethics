1. 우리가 만든 자료, 어떻게 배포할까?

📁 방식 A: .html 파일 직접 제공

  • 장점: 인터넷 없이도 실행 가능.
  • 단점 (갤럭시 탭 환경): 학생들이 '내 파일'에서 다운로드 폴더를 찾아 실행하기가 매우 어렵습니다.
  • 보안 문제: 파일 직접 실행 시 보안 정책으로 인해 이미지가 깨지는 현상 발생.
  • 유지보수: 오타 하나를 고쳐도 파일을 처음부터 다시 배포해야 함.

🌐 방식 B: 서버에 업로드 (URL 링크 제공)

  • 장점: 탭에서 링크(URL) 클릭 한 번으로 즉시 실행!
  • 장점: 교사가 코드를 수정하면 새로고침 시 전원 동시 반영!
  • 장점: 이미지 깨짐 등의 복잡한 보안 에러가 없음.
🎯

학교 현장에서는
'서버에 업로드 이후 - 링크(URL/QR코드) 배포'를 추천합니다.

  • 학생들에게 다운로드 링크를 제공하는 것...
  • 다운로드 이후 태블릿에서 html 파일을 찾는 것...
  • 갑자기 수정할 수도 있는 것...

등의 이유로 서버를 통한 링크 배포가 좋습니다.

2. 서버 배포: GitHub Pages 활용

무료 서비스인 GitHub Pages를 활용하면, 내 컴퓨터의 HTML 코드를 렌더링 하여진짜 웹사이트로 배포할 수 있습니다.

💡 배포 필수 프롬프트

"배포하기 쉽도록 모든 CSS는 <style> 태그 안에, 자바스크립트는 <script> 태그 안에 넣어서 HTML 파일 딱 한 개로 병합해 줘."

⚠️ 데이터 수집의 한계

단순 HTML 파일 배포로는 학생의 점수를 선생님 컴퓨터로 모을 수 없습니다. 이를 위해서는 데이터베이스 등 추가적인 기능이 구현되어야 합니다. html 수준에서 수집이 필요하다면 HTML 안에 구글 설문지(iframe)를 포함하라고 지시하세요.

  </ul>

Q. 딜레마 상황

내일 당장 발표인데, 발표 자료에 딱 어울리는 유료 폰트를 인터넷 블로그에서 무료로 구했습니다. 어떻게 할까요?

실습 2. 딜레마 극장

2단계: HTML/JS 동작 개선

"설명 버튼을 누르면 알림창(alert)이 뜨는 대신, 숨겨져 있던 <div id="explanation"> 상자가 화면 아래에 짠 하고 나타나도록 자바스크립트(display: block)와 HTML 구조를 수정해 줘."

🎯 목표: 팝업 경고창 대신 자연스러운 토글(Toggle) UI로 변경합니다.

<!-- 요소를 숨겨두고 클릭 시 보이게 함 -->
<button id="showBtn">상황 설명 보기</button>
<div id="explanation" style="display: none;">
  💡 해설: 무료 폰트라도 상업적 사용은...
</div>

<script>
  document.getElementById("showBtn")
    .addEventListener("click", function() {
      document.getElementById("explanation")
        .style.display = "block";
  });
</script>
▶ 브라우저 실행 화면 (화면 내 토글)

상황: 유료 폰트를 무료로 구했습니다.

💡 해설: 무료로 공유된 폰트라도 상업적/공식적 발표에 무단 사용하면 저작권 침해가 될 수 있습니다!
실습 2. 딜레마 극장

3단계: CSS 인터랙션 디자인

"A, B 선택지 버튼을 예쁜 카드 모양으로 만들어줘. 버튼에 마우스를 올리면(:hover) 카드가 위로 살짝 떠오르고(transform) 테두리 색상이 파란색으로 변하게 부드러운 움직임(transition)을 CSS로 추가해 줘." 

<style>
  .choice-card {
    padding: 20px;
    border: 2px solid #ccc;
    border-radius: 10px;
    cursor: pointer;
    transition: all 0.3s ease; /* 부드러운 전환 */
  }
  .choice-card:hover {
    transform: translateY(-5px); /* 공중 부양 */
    border-color: #3b82f6;       /* 파란 테두리 */
  }
</style>

실습 3. 피싱/스미싱 감별사

3단계: CSS 모바일 UI 완성

"전체 상자(#phone)의 너비를 350px로 고정하고 비율을 스마트폰처럼 세로로 길게 해 줘. 테두리는 둥글게 깎아줘. 상대방 말풍선(msg-other)은 회색 바탕으로 왼쪽에 붙게 하고, 모서리를 둥글게 처리해 줘." 

<style>
  #phone {
    width: 350px; height: 600px;
    border: 15px solid #1f2937; /* 스마트폰 베젤 */
    border-radius: 40px;
    background-color: #9bbbd4;  /* 대화방 배경 */
  }
  .msg-other {
    background-color: white; padding: 15px;
    border-radius: 20px; max-width: 80%;
  }
</style>
