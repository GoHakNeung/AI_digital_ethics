생성형 AI와 소통하며 나만의 교육용 웹 프로그램을 만드는 첫걸음입니다.

1 프롬프트 작성 방법

1. 설명

생성형 AI에게 질문할 때, 단순히 결과만 요구하는 것이 아니라 '역할, 상황, 목적' 등 충분한 맥락(Context)을 대화창(Prompt) 안에 미리 제시하여 AI가 내 의도를 정확히 파악하게 만드는 기법입니다.

2. 인-컨텍스트 러닝 (In-Context Learning)

생성형 AI는 문맥을 이해합니다. 즉, 대화 기록을 고려해서 답을 제공합니다.

앞서 채팅 기록을 고려해서 질문-답을 해야 합니다. 즉, 대화 주제가 바뀌면 새로운 채팅을 시작해야 합니다.

앞서 코드에 대한 설명을 질문했다면, 이에 대한 설명은 생략해도 됩니다.

3. 프롬프트 예시

"지구의 공전에 대한 시뮬레이션 자료를 html로 만들려고 한다. 지구의 관점에서 보는 것과, 태양의 관점에서 보는 것 만들어 줘."

"방위를 지구, 태양에 입력해 줘."

두 번째 프롬프트의 경우 지구 공전 시뮬레이션을 말하지 않았지만 첫 번째 프롬프트를 통해 지구 공전임을 알고, 기존 생성한 코드에 수정해 줍니다.

2 프롬프트로 코드 요청하는 방법

1. 설명

원하는 결과물을 얻기 위해 구조, 디자인, 기능을 분리하여 구체적으로 명령합니다. 오늘 1차시에서는 디자인(CSS)과 기능(JS)을 제외하고 오직 구조(HTML)만 요청 하는 것에 집중합니다.

2. HTML을 알고 프롬프트를 작성하면 좋은 점

HTML은 결과물이 눈에 보입니다. 내가 원하는 구조를 설명할 수 있고, 그 결과물을 확인할 수 있습니다.

HTML에 대한 지식이 알고 있다면 AI에 구체적으로 요청할 수 있고, 수정할 때도 수정할 곳을 구체적으로 요청할 수 있습니다.

3. 프롬프트 예시

"디지털 시민성 선서문 페이지를 만들어줘. 다른 건 다 빼고 오직 HTML 코드만 사용해. 화면에는 큰 제목 1개, 설명 글 2줄, 학생 이름 입력칸, '서약하기' 버튼이 순서대로 들어가야 해."

3 코드 수정 요청 방법 (반복과 개선)

1. 설명

AI가 처음부터 완벽한 코드를 주지 않을 수 있습니다. 이때 처음부터 다시 요청하지 않고, 이전 대화를 바탕으로 "특정 부분만" 콕 집어 수정(추가/삭제/변경)을 요구 합니다.

3. 프롬프트 예시

"방금 짜준 코드에서 '서약하기' 버튼 위에 '개인정보 보호 수칙에 동의합니다'라는 체크박스를 하나 추가해 줘. 나머지 코드는 그대로 유지해."

4 활용 가능한 생성형 AI 도구 비교

1. 설명

  • Microsoft 365 Copilot: 기관 계정(교육청, 교대)으로 사용할 수 있으며, gpt5.5, 5.6 사용 가능.
  • Claude : 코딩 능력(haiku < sonnet < opus)이 우수하며, claude 디자인과 같이 사용 가능.
  • Gemini: 생성된 HTML 코드를 브라우저에서 바로 다운로드/실행 가능한 환경 제공(초보자 실습에 최적).

2. 특징

무료/유료 버전에 상관없이 간단한 수준의 HTML 코드는 완성도 높게 제공해줍니다.

gemini의 경우 코드를 다운로드 받을 수 있어 초보자에게 편하며

Copilot의 경우 윈도우11에 내장되어 있어 접근이 쉽습니다.

Microsoft 365 Copilot은 기관 계정이 필요하며(무료로 생성), GPT 높은 버전을 사용할 수 있습니다.

claude는 디자인과 사용하는 경우 높은 품질의 자료를 받을 수 있습니다.

5 웹앱(Web App)이란?

1. 설명

웹 브라우저(크롬, 엣지, 사파리 등)만 있으면 기기의 종류(PC, 태블릿, 스마트폰)나 운영체제에 상관없이 인터넷을 통해 바로 실행되는 프로그램입니다.

즉, 실행을 위해 추가로 설치해야하는 프로그램이 없습니다.

💡 교사 활용 범위: 학생용 윤리 퀴즈, 과학/수학 변인 통제 시뮬레이션, 학급 규칙 동의서, 타이머 등 수업용 미니 도구 제작 가능.

2. 활용 방안

  • 로컬 : 내 PC에서 .html 파일 실행(브라우저 이용)
  • 서버 : 특정 PC(또는 서버)에서 .html 파일 실행(브라우저 이용)

    • 6 교육 현장에서 웹앱의 장점

    1. 설명

    • ✔️ 무설치: 학생들에게 앱이나 프로그램을 별도로 설치하라고 안내할 필요가 없습니다.
    • ✔️ 즉각적인 배포: 링크(URL) 하나나 QR코드만 주면 전체 학생이 동시에 접속하여 수업을 시작할 수 있습니다.
    • ✔️ 유지보수: 교사가 코드를 조금만 수정해서 다시 올리면 학생들은 새로고침(F5)만으로 업데이트된 버전을 볼 수 있습니다.

    7 웹 페이지를 구성하는 3요소

    1. 설명

    HTML (뼈대)

    화면에 어떤 요소(글, 그림, 버튼)가 어디에 들어갈지 구조를 정의합니다.

    CSS (디자인)

    요소의 색상, 크기, 폰트, 배치 등을 아름답게 꾸며줍니다. (2차시)

    JavaScript (근육)

    버튼을 눌렀을 때 팝업이 뜨거나 점수를 계산하는 등 동적인 기능을 담당합니다.

    8 HTML 기본 구조

    1. 설명

    웹 문서를 작성하기 위한 가장 기본적인 틀입니다. <!DOCTYPE html>로 문서 종류를 선언하고, <html> 안에 눈에 안 보이는 정보 <head>와 실제 보이는 내용 <body>를 넣습니다.

    2. 예시 코드

    <!DOCTYPE html>
<html>
  <head>
    <title>디지털 윤리 수업</title>
  </head>
  <body>
    (이곳에 내용이 들어갑니다)
  </body>
</html>

    3. 프롬프트 예시

    "디지털 윤리 퀴즈를 만들 건데, HTML 기본 구조(head, body)를 갖춰서 코드를 짜줘."

    9 시맨틱 구조 나누기 (header, main, footer)

    1. 설명

    화면을 의미에 따라 상단(제목/메뉴), 중단(본문), 하단(저작권/제작자)으로 나누는 태그입니다. AI가 화면을 논리적으로 짜도록 유도합니다.

  <h1>우리학급 디지털 규칙</h1>

</main>

<footer>

</footer>

    11 제목, 본문, 구역 묶기 (h1~h6, p, div)

    1. 설명

    • h1~h6: 제목을 나타내며 숫자가 작을수록 큽니다.
    • p: 일반적인 본문(단락)을 작성합니다.
    • div: 여러 요소를 하나의 상자로 묶어 레이아웃을 잡습니다.

    2. 예시 코드

    <div>
  <h2>1. 사이버 폭력이란?</h2>
  <p>사이버 공간에서 타인에게 피해를 주는 행위입니다.</p>
</div>

    3. 프롬프트 예시

    "질문과 답변을 하나의 div 상자로 묶어줘. 질문은 두 번째로 큰 제목(h2)으로 하고, 설명은 일반 본문 단락(p)으로 써줘."

    실행 미리보기

    1. 사이버 폭력이란?

    사이버 공간에서 타인에게 피해를 주는 행위입니다.

    12 목록 (ul, ol, li)

    1. 설명

    항목을 나열할 때 사용합니다. ul은 순서가 없는 점(•)으로, ol은 1, 2, 3 같은 숫자로 순서를 매깁니다. 각 항목은 li를 사용합니다.

    2. 예시 코드

    <ol>
  <li>출처 반드시 남기기</li>
  <li>비밀번호 공유하지 않기</li>
</ol>

    3. 프롬프트 예시

    "올바른 인터넷 사용 습관 3가지를 번호가 매겨지는 순서 있는 목록(ol)으로 정리해 줘."

<iframe src="https://www.youtube.com/..."></iframe>

    15 텍스트 꾸미기 (strong, b, u, i)

    1. 설명

    글자의 일부분만 강조할 때 씁니다. strong 또는 b는 굵게, u는 밑줄, i는 기울임꼴입니다.

</p>

    18 슬라이더와 숫자 입력 (range, number)

    19 날짜와 색상 선택 (date, color)

    20 비밀번호 입력 (password)

    1. 설명

    입력하는 내용을 남이 볼 수 없도록 글자 대신 까만 점(●)으로 가려주는 입력창입니다. 디지털 윤리 중 보안/개인정보 교육에 활용하기 좋습니다.

    2. 예시 코드

    비밀번호: <input type="password">

    3. 프롬프트 예시

    "안전한 비밀번호 만들기 실습을 할 거야. 학생들이 입력할 때 글자가 가려지도록 비밀번호 입력칸(password)을 하나 만들어줘."

    실행 미리보기

    21 입력창 디테일 속성 (placeholder, value)

    1. 설명

    • placeholder: 빈칸에 희미하게 적혀 있는 '안내/예시 문구'입니다. 글자를 치면 사라집니다.
    • value: 처음부터 빈칸에 실제 문자가 채워져 있는 '기본값'입니다.

    2. 예시 코드

    이름: <input type="text" placeholder="예: 홍길동">
학교명: <input type="text" value="우리초등학교">

    3. 프롬프트 예시

    "이름 입력칸에는 회색 글씨로 '예: 홍길동'이라는 안내 문구(placeholder)가 보이게 해주고, 소속 학교 입력칸에는 처음부터 '인공지능대학원'이라는 글씨가 채워져 있도록(value) 코드를 짜줘."
